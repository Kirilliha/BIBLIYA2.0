# Система управления библиотекой - АИС

## Описание проекта
Автоматизированная информационная система для управления библиотекой. Система позволяет:
- Управлять каталогом книг (добавление, редактирование, удаление, поиск)
- Управлять читателями библиотеки
- Вести учет выдачи и возврата книг
- Просматривать статистику работы библиотеки

## Технологии
- **Backend**: Python 3, Flask
- **Database**: SQLite3
- **Frontend**: HTML5, CSS3, Jinja2 Templates
- **Архитектура**: Клиент-серверная (веб-приложение)

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
python app.py
```

### 3. Добавление тестовых данных (опционально)
```bash
python add_test_data.py
```

### 4. Открыть в браузере
```
http://localhost:5000
```

## Структура базы данных

### Таблица books (Книги)
- id - уникальный идентификатор
- title - название книги
- author - автор
- isbn - международный стандартный книжный номер
- publisher - издательство
- year - год издания
- category - категория
- quantity - общее количество экземпляров
- available - доступно для выдачи
- created_at - дата добавления

### Таблица readers (Читатели)
- id - уникальный идентификатор
- full_name - ФИО
- email - электронная почта
- phone - телефон
- address - адрес
- registration_date - дата регистрации

### Таблица loans (Выдача книг)
- id - уникальный идентификатор
- book_id - ID книги
- reader_id - ID читателя
- loan_date - дата выдачи
- return_date - дата возврата
- status - статус (active/returned)

## Функциональные возможности

### Управление книгами
- Просмотр каталога книг
- Добавление новых книг
- Редактирование информации о книгах
- Удаление книг
- Поиск по названию, автору, ISBN
- Фильтрация по категориям

### Управление читателями
- Просмотр списка читателей
- Регистрация новых читателей
- Редактирование данных читателей
- Удаление читателей
- Поиск по имени, email, телефону

### Учет выдачи книг
- Выдача книг читателям
- Возврат книг
- Просмотр истории выдач
- Отслеживание активных выдач

### Статистика
- Общее количество книг
- Количество зарегистрированных читателей
- Количество активных выдач
